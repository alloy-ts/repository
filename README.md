# Repository

Versioned repository for yumin-chen projects.

## SQL Schema Compiler & Diesel NAPI Runtime

The SQL schema compiler compiles schema definitions written in JavaScript/TypeScript into validated Rust models, Diesel tables, NAPI-RS bindings, and SQL DDL for SQLite and PostgreSQL, along with schema diff migrations.

### Architecture: 5 Internal Layers

1. **JavaScript / TypeScript API**: Fluent DSL (`defineSchema`, `table`, column builders, `Database`, repository operations, transactions).
2. **NAPI Binding Layer**: Bridges JS and Rust types, validates arguments, handles promises, maps error codes.
3. **Query Abstraction Layer**: Strategy C (Hybrid) model matching compile-time typed Diesel structs with ergonomic query and filter execution.
4. **Diesel Integration Layer**: `diesel::table!`, `joinable!`, `Queryable`, `Selectable`, `Insertable`, connection pools, transactions.
5. **Database Backend**: SQLite (with WAL and foreign keys) and PostgreSQL (with enum types and UUID/JSONB).

### Backend Support Matrix

| IR Type | SQLite Backend | Postgres Backend | Rust Type |
|---|---|---|---|
| `integer` | `INTEGER` | `INTEGER` / `SERIAL` | `i32` |
| `bigint` | `INTEGER` | `BIGINT` | `i64` |
| `float` | `REAL` | `REAL` | `f32` |
| `double` | `REAL` | `DOUBLE PRECISION` | `f64` |
| `boolean` | `INTEGER` (0/1) | `BOOLEAN` | `bool` |
| `timestamp` / `timestamptz` | `TEXT` (`CURRENT_TIMESTAMP`) | `TIMESTAMPTZ` (`NOW()`) | `chrono::DateTime<Utc>` |
| `uuid` | `TEXT` | `UUID` | `uuid::Uuid` |
| `json` | `TEXT` | `JSONB` | `serde_json::Value` |
| `enum` | `TEXT` + `CHECK` constraint | `CREATE TYPE ... AS ENUM` | Generated Rust Enum |

### Code Generation & Migrations

- To generate code explicitly: `npm run generate` (or `node scripts/generate.mjs --schema schema.js --out src/generated`).
- Schema migrations are generated by comparing snapshot IRs with `generate_migration`.
